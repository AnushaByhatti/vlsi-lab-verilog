# VLSI Lab - Verilog HDL Programs & Testbenches

Verilog HDL code and testbenches written as part of academic VLSI / Digital 
Design coursework (6th Semester, B.E. Electronics & Communication, 
Government Engineering College, Haveri - VTU Belagavi).

## Tools Used
- **Xilinx (ISE/Vivado)** - Synthesis and simulation
- **DSCH** - Schematic capture and simulation
- **Microwind** - CMOS layout design

## Contents
| File | Description |
|------|-------------|
| `logic_gates.v` | Basic logic gate implementations (AND, OR, NOT, NAND, NOR, XOR, XNOR) |
| `mux.v` | Multiplexer design (Verilog) |
| `demux.v` | Demultiplexer design (Verilog) |
| `flipflop.v` | Flip-flop designs (D, JK, SR, T) |
| `counter.v` | Synchronous/asynchronous counter design |
| `*_tb.v` | Corresponding testbenches for functional verification |

## About
This repository documents hands-on lab work covering the digital design 
flow — from writing Verilog RTL code, to verifying functionality through 
self-written testbenches, to schematic and layout design.
